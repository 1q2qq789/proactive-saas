# 评分模型说明

## 风险评分公式

```
Risk Score = Impact × Probability × Urgency
```

### 维度说明

| 维度 | 范围 | 含义 |
|------|------|------|
| **Impact** | 1-10 | 这个问题如果触发，后果有多严重 |
| **Probability** | 1-10 | 这个问题多久内可能触发 |
| **Urgency** | 1-10 | 需要多快处理 |

### 等级定义

| 分数范围 | 颜色 | 行动 |
|----------|------|------|
| 1-29 | 🟢 通过 | 记录即可，后续观察 |
| 30-59 | 🟡 警告 | 建议安排时间处理 |
| 60-100 | 🟠 需关注 | 建议在本次会话处理 |
| 101-1000 | 🔴 紧急 | 立即处理 |

### Impact 判定表

| 分值 | 场景示例 |
|------|---------|
| 1-3 | 格式问题、轻微风格不一致 |
| 4-6 | 逻辑断层、追问盲区、数据口径不清 |
| 7-8 | 数据冲突、版本时间线矛盾、缺失关键定义 |
| 9-10 | 数据完全错误、致命逻辑漏洞、安全风险 |

### Probability 判定表

| 分值 | 场景示例 |
|------|---------|
| 1-2 | 边缘场景，几乎不会发生 |
| 3-5 | 特定条件下触发 |
| 6-8 | 大概率在下次审视时被发现 |
| 9-10 | 立即或马上就会被发现 |

### Urgency 判定表

| 分值 | 场景示例 |
|------|---------|
| 1-3 | 可以等下次迭代 |
| 4-6 | 建议在本次会话处理 |
| 7-8 | 必须在本会话处理 |
| 9-10 | 需要在回答下一句话之前解决 |
